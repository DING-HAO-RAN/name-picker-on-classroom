# 名字抽取器

一个给课堂用的**离线随机点名桌面应用**。导入一份名单就能抽取学生，支持按权重抽取、保底池、抽取音效、多种动画样式与全屏结果展示；窗口标题栏按应用主题自绘，关闭后可缩到后台由悬浮球唤回。

名单、权重、保底池、音效与历史记录全部只保存在本机。应用不上传姓名、不联网、不含自动更新与遥测。

- 技术栈：Electron 36 + React 19 + TypeScript 5.8 + electron-vite
- 目标平台：Windows 10/11 x64

## 下载

从 Releases 页面获取编译好的 Windows x64 程序：

- **NamePicker-Setup.exe**：NSIS 安装包，可选安装位置和快捷方式，能在「应用和功能」里卸载

两个产物均未做代码签名，Windows SmartScreen 会提示「未知发布者」，需要点「更多信息 → 仍要运行」。

## 功能一览

### 抽取

- **名单导入**：支持 `txt` / `csv` / `xlsx`，导入后即可调整抽取人数
- **加权抽取**：学生权重以百分比（0-100，支持小数）表示，100 为标准概率，0 表示暂不参与
- **权重滑动条**：每个学生一行滑动条，拖动即可调权重，与数字输入框联动
- **一键统一权重**：输入一个百分比，把全部学生恢复为等概率
- **权重预设**：把调好的权重方案保存为预设（保存在本机），随时从下拉框套用或删除
- **按星级抽取**（可选开启）：勾选参与的星级，抽取范围限定在勾选的星级内
- **保底池**：从名单中勾选重点关注的同学组成保底池，设定保底次数；连续抽取达到次数仍未抽中保底池成员时，下一次抽取必定命中，抽中后计数自动清零
- **允许重复抽取**：开启后已抽中的同学仍可再次被抽中（单次抽取多人时互不重复）
- **重置本轮**：一键清空本轮已抽中状态，重新开始

### 动画与结果

- **三种动画样式**：大卡片滚动（默认）、学生列表跳跃跑马灯、全屏聚焦弹窗轮播
- **抽卡式动画**：星穹夜幕舞台上卡牌先从牌堆飞出落位，点击翻面揭晓（抬升、翻转、落定的完整动作）；卡面颜色随学生星级变化（1 白 / 2 蓝 / 3 紫 / 4 红 / 5 金，含顶部色带与同色描边），卡面展示姓名与星星图案，命中保底池的卡牌带金色流光
- **星级系统**：可在设置中为每个学生设定 1-5 星（默认 1 星），导入名单时也可直接携带星级（TXT 在名字后用空格跟数字，表格写在第二列）；学生每被抽中 5 次自动升 1 星，最高升到 4 星；在设置中修改星级时，若名单文件仍在导入时的位置，会自动同步回文件（文件被移动后静默忽略）
- **动画时长**：0 - 5000 毫秒可调；名字切换用缓出曲线加随机抖动，先快后慢，最后一刻才定格
- **全屏结果展示**：停留时长默认 3 秒（1500 - 10000 毫秒可调），名字卡纯白高对比显示
- **抽取音效**（可选开启）：名字定格时播放音效；抽中保底池成员时可播放特殊音效。支持 MP3、WAV、OGG 等，可试听、更换、清除

### 外观

- **明亮 / 深色主题**
- **五种颜色主题**：墨青（默认）、暖阳、青禾、黛蓝、绛霞——主色与界面底色整体替换，动画与结果显示界面同步换色
- **自定义背景图**：选择本机图片作为主界面背景，拉伸铺满、完整显示，标题栏自动改为毛玻璃融入
- **个性化**：主界面标题、窗口标题、程序名字、标题栏文字与程序图标（窗口图标）均可自定义，随存档保存、启动即生效

### 窗口与系统

- **后台运行**：点击关闭默认缩到后台，屏幕出现置顶悬浮球（可拖动、可触控），单击回到主界面，右键菜单可真正退出；也可以在设置中改为「直接退出」或关闭悬浮球
- **开机自启**：设置中一键开关，登录 Windows 时自动启动
- **历史记录**：保留最近 50 次抽取结果，可随时清除
- **本机数据**：设置里可清除保存在本机的全部数据（二次确认）
- 所有开关均为胶囊式切换开关，带滑块动画，触控友好；数字输入框为草稿态，输入过程不被打断

## 键盘快捷键

- `空格` / `S`：开始抽取
- `R`：重置本轮
- `Ctrl/Cmd + O`：导入名单

## 快速开始（开发者）

环境要求：Node.js 20 及以上、npm。

```powershell
npm install
npm run dev          # 启动 Electron 开发模式
npm test -- --run    # 单元测试（vitest + Testing Library）
npm run build        # 构建主进程、预加载脚本与渲染器资源
npm run test:e2e     # 先构建，再用 Playwright Electron 跑端到端流程
```

## 打包

```powershell
npm run package:win
```

产出 NSIS 安装包与 portable 便携包（x64，输出到 `release/`）。如果构建机缺少创建符号链接的权限，可用受限模式：

```powershell
$env:NAME_PICKER_SKIP_RESOURCE_EDIT = '1'
npm run package:win
Remove-Item Env:NAME_PICKER_SKIP_RESOURCE_EDIT
```

## 数据与安全边界

- 数据只落在本机，通过主进程的本地存储读写，无网络请求、无遥测、无自动更新
- 渲染器只能通过预加载层暴露的 `window.namePicker` 访问主进程能力（`contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`）
- 名单导入在主进程校验扩展名与解析结果，错误信息经固定文案映射后返回，不把路径或堆栈抛给界面

## 项目结构

```text
src/
  main/       主进程：窗口、悬浮球、IPC 处理器、名单导入、本地存储
  preload/    预加载：通过 contextBridge 暴露 window.namePicker
  renderer/   渲染器：React 界面、抽取动画节奏、颜色主题、样式
  shared/     主进程与渲染器共用的类型与 IPC 契约
tests/        端到端用例与虚构夹具
docs/         发布验收清单
```
